# First-release workflow coverage

Each row follows the order of the acceptance criteria in [issue #48](https://github.com/F1nal04/tikkit/issues/48). Rust tests are under `apps/api/tests/`. The browser tests under `apps/web/e2e/` exercise rendering and client behavior against a stub. The full browser scenarios under `apps/web/e2e-full/` exercise the built portal, real API, and PostgreSQL. Tests marked “add” are the Phase 1 work list.
